## 2. 安装验证（本机）

| # | 检查项 | 做法 | 通过标准 |
|---|---|---|---|
| 2.1 | 静默安装 | `Start-Process .\release\StudyFlow-<ver>-setup.exe -ArgumentList '/S' -Wait` | 装到 `%LOCALAPPDATA%\Programs\StudyFlow` |
| 2.2 | 快捷方式 | 桌面 / 开始菜单 | 都指向安装版 exe |
| 2.3 | 启动 | 从资源管理器双击 | 窗口标题 `StudyFlow · 学习进度`，无白屏 |
| 2.4 | 老库兼容 | 用已有 `%APPDATA%\StudyFlow\studyflow.db` 打开 | 目标/计划/进度都在，无 `no such table` |
| 2.5 | 主要路径 | 看板 → Day → 教案空态 → 设置 | 不报错；有 Key 时跑一次检测 |
| 2.6 | SmartScreen | 首次双击安装包 | 记录提示文案（未签名必然出现「未知发布者」） |

> 本机从**被注入了 `ELECTRON_RUN_AS_NODE` 的终端**启动 exe 会秒退（exit 0、无窗口）：
> `cmd /c "set ELECTRON_RUN_AS_NODE=&& start "" "<exe>"`。用户双击不受影响。
