StudyFlow
AI 监督式学习进度 · Windows 桌面应用

让进度条只为「真的学会」增长

设定学习目标，AI 拆成每天能照着做的任务；点「让 AI 备课」拿到当天讲义；做完打勾后参加检测—— 7 道单选 + 2 轮问答，80 分才算通过。数据只存在你自己的电脑上。

下载__VERSION__

安装版（推荐） NSIS 安装包 · 约 127 MB 便携版 双击即用 · 约 111 MB

两个包都在 Releases 页面。 没有代码签名，Windows 可能提示「未知发布者」，选择「仍要运行」即可。

第一次使用

  • 创建本地账号（不联网，忘记密码无法找回）
  • 在「设置」里填自己的 DeepSeek API Key，Key 用系统加密存在本机
  • 新建目标 → AI 生成计划 → 进 Day 点「让 AI 备课」
  • 勾任务、直接检测、看进度条涨起来

从源码构建

  • git clone https://github.com/shilingxiaoa/StudyFlow.git
  • npm install → npm run dev
  • 打包：npm run dist（产出在 release/）
